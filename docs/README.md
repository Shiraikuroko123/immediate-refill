# Immediate Refill research page

[English](https://shiraikuroko123.github.io/immediate-refill/) · [中文](https://shiraikuroko123.github.io/immediate-refill/zh.html)

Open either page to replay the three-request example, read the optimality condition, compare device measurements with archived experiments and download the paper or evidence bundle. The static pages include the complete result text and paper figures when JavaScript is disabled.

Serve this directory with `python -m http.server 4173 --bind 127.0.0.1`. The site uses relative links for GitHub Pages project hosting. The two localized HTML files share `app.js`, `schedule.js` and the two stylesheets. Fonts are self-hosted and their licenses are in `assets/type/`.
